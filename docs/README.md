# Tài liệu kỹ thuật

Thư mục này chứa các tài liệu kỹ thuật được cập nhật xuyên suốt dự án. Yêu cầu mô tả hệ thống **phải làm gì**. Các đặc tả và tài liệu kiến trúc sau đó sẽ mô tả nhóm dự định triển khai **như thế nào**.

Không được âm thầm thay đổi giá trị của một yêu cầu. Hãy ghi nhận thay đổi, cập nhật trạng thái của yêu cầu, đồng thời cập nhật ca kiểm thử và dòng truy vết liên quan.
